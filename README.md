# ColorfulDesktopSelect
This is a little application that I made to change the color of the select area on desktop.
<img width="960" height="600" alt="Desktop" src="https://github.com/user-attachments/assets/cb868808-bbe1-4d01-9093-ea4b36c083ee" />

### Showcase
[![Showcase](https://img.youtube.com/vi/2cFVwhGjyIA/maxresdefault.jpg)](https://youtu.be/2cFVwhGjyIA)

### Usage
You can choose a custom color or use the accent color. The accent color changes automatically.
To make it run on startup, place the application in the `shell:startup` folder.
